Selected research code and computational workflows from my research at the University of Utah, with a focus on numerical weather prediction and data assimilation.

## Contents

- **`research/`** — WRF/WRFDA and GSI/EnKF research experiments and workflows.
- **`coding-fortran/`** — Selected Fortran utilities for scientific data processing and GSI diagnostics.
- **`installation/`** — Historical GSI/EnKF source-code development, including original and modified EnKF source for comparison.

Large datasets, model output, compiled executables, and other generated files are excluded.
